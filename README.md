# SAO-SURIN-MAP
# 🗺️ SAO-SURIN MAP 2570

**ระบบแผนที่แสดงผลการตรวจสอบ ติดตาม และให้คำปรึกษาแนะนำ “สิ่งก่อสร้างไม่ใช้ประโยชน์” จังหวัดสุรินทร์**  
สำนักตรวจเงินแผ่นดินจังหวัดสุรินทร์ | ปีงบประมาณ พ.ศ. 2570

> ระบบเผยแพร่ข้อมูลเพื่อสนับสนุนการตรวจสอบ ติดตาม และการใช้ประโยชน์จากสิ่งก่อสร้างของรัฐอย่างคุ้มค่า **การปรากฏชื่อโครงการไม่ได้หมายความว่ามีข้อยุติว่ากระทำผิดหรือเกิดความเสียหาย**

## ภาพรวม

ระบบแสดงข้อมูลเริ่มต้น **16 โครงการ** บนแผนที่ OpenStreetMap โดยใช้ตำแหน่งอ้างอิง **ระดับตำบล** เมื่อยังไม่มีพิกัดสถานที่ก่อสร้างที่ยืนยันแล้ว โครงการในตำบลเดียวกันอาจแสดงหมุดใกล้กันหรือรวมกันตามการจัดกลุ่มของแผนที่

## ความสามารถ

- แสดงหมุดโครงการและรายละเอียดชื่อโครงการ ตำบล อำเภอ หน่วยงาน งบประมาณ และสถานะ
- กรองโครงการตามกลุ่มสถานะ
- เพิ่ม แก้ไข และจัดการข้อมูลโครงการผ่านหน้าเว็บ
- ระบุละติจูดและลองจิจูดเมื่อมีข้อมูลที่ยืนยันแล้ว
- ส่งออกและนำเข้าข้อมูลรูปแบบ JSON เพื่อสำรองหรือย้ายข้อมูล
- บันทึกข้อมูลที่แก้ไขไว้ใน `localStorage` ของเบราว์เซอร์เครื่องที่ใช้งาน
- ใช้งานได้ทั้งคอมพิวเตอร์และโทรศัพท์ผ่านเว็บเบราว์เซอร์

## เริ่มใช้งาน

1. เปิดไฟล์ `index.html` ในเว็บเบราว์เซอร์ หรือเผยแพร่ผ่าน GitHub Pages
2. รอให้แผนที่พื้นหลังและตำแหน่งระดับตำบลโหลดเสร็จ
3. คลิกหมุดเพื่อดูข้อมูล หรือเลือกตัวกรองสถานะ
4. ใช้ปุ่ม **เพิ่มโครงการ** เพื่อเพิ่มรายการ และ **ส่งออก JSON** เพื่อสำรองข้อมูล

> ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลด Leaflet, แผนที่ OpenStreetMap และบริการค้นหาตำแหน่งระดับตำบล บางพื้นที่อาจค้นหาตำแหน่งไม่สำเร็จ

## โครงสร้างไฟล์

```text
SAO-SURIN-MAP/
├── index.html       # หน้าแผนที่และระบบจัดการข้อมูล
└── README.md        # คู่มือโครงการ
```

หากนำระบบไว้ในโฟลเดอร์ `public_map/` ให้ปรับเส้นทาง URL ให้ตรงกับตำแหน่งไฟล์จริง

## เผยแพร่ด้วย GitHub Pages

1. อัปโหลด `index.html` และ `README.md` ไปยัง repository นี้
2. เปิด **Settings → Pages**
3. เลือก **Deploy from a branch** แล้วกำหนด branch `main` และโฟลเดอร์ `/ (root)`
4. บันทึกและรอระบบเผยแพร่ จากนั้นเปิด URL ของ GitHub Pages ที่แสดงในหน้าตั้งค่า

หากใช้ชื่อ repository `SAO-SURIN-MAP` และบัญชี `urr2556-png` ที่ตั้งค่า Pages สำเร็จ URL ตามรูปแบบมาตรฐานจะเป็น `https://urr2556-png.github.io/SAO-SURIN-MAP/` **โปรดตรวจสอบว่ามีการเผยแพร่จริงก่อนแชร์**

## วิธีปรับปรุงข้อมูล

1. กด **เพิ่มโครงการ** หรือเลือกแก้ไขรายการเดิม
2. กรอกชื่อโครงการ ตำบล อำเภอ หน่วยงาน วงเงิน และสถานะ
3. หากมีพิกัดที่ตรวจสอบแล้วจึงกรอกละติจูด/ลองจิจูด; หากไม่มีให้เว้นว่าง
4. กดบันทึก แล้วใช้ **ส่งออก JSON** เพื่อเก็บสำรอง
5. ในเครื่องอื่น ใช้ **นำเข้า JSON** เพื่อนำข้อมูลชุดเดียวกันมาใช้งาน

**ข้อจำกัดสำคัญ:** การแก้ไขบนหน้าเว็บถูกบันทึกเฉพาะเบราว์เซอร์ของผู้แก้ไข ไม่ได้อัปเดตไฟล์ใน GitHub หรือฐานข้อมูลกลางโดยอัตโนมัติ หากต้องการให้ประชาชนทุกคนเห็นข้อมูลใหม่พร้อมกัน ต้องปรับปรุงข้อมูลต้นทางและเผยแพร่เวอร์ชันใหม่ หรือพัฒนาการเชื่อมต่อฐานข้อมูลกลางเพิ่มเติม

## ความหมายของสถานะ

| สถานะ | ความหมาย |
|---|---|
| ใช้ประโยชน์แล้ว | แก้ไขปัญหาและใช้ประโยชน์แล้ว |
| ติดตามความคุ้มค่า | เปิดใช้หรือปรับปรุงแล้ว อยู่ระหว่างติดตามผล |
| กำลังแก้ไข | หน่วยงานอยู่ระหว่างดำเนินการแก้ไขปัญหา |
| วางแผนตรวจสอบ | อยู่ระหว่างวางแผนตรวจสอบและ/หรือให้คำปรึกษาแนะนำ |

## ความถูกต้องของข้อมูลและข้อสงวน

- จุดอ้างอิงระดับตำบล **ไม่ใช่พิกัดสถานที่ก่อสร้างจริง**
- ข้อมูลโครงการที่ 16: “ระบบสถานีสูบน้ำ ถูกทิ้งร้างกว่า 20 ปี” ระบุพื้นที่ตามข้อมูลที่ได้รับว่า **ตำบลศรีณรงค์ อำเภอชุมพลบุรี จังหวัดสุรินทร์** และหน่วยงาน **อบต.ศรีณรงค์** ซึ่ง **ยังต้องตรวจสอบยืนยันชื่อพื้นที่และหน่วยงาน** ก่อนใช้เป็นข้อมูลทางราชการหรือปักหมุดจริง
- โครงการที่อยู่ระหว่างวางแผนตรวจสอบไม่ถือเป็นผลการตรวจสอบที่มีข้อยุติ
- ไม่ควรตีความวงเงินโครงการว่าเป็นจำนวนเงินความเสียหาย
- ข้อมูลควรได้รับการตรวจสอบกับเอกสารราชการก่อนเผยแพร่เป็นข้อเท็จจริงยืนยันแล้ว
